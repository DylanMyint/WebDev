Web Technologies

HTML

HTML stands for Hyper Text Markup Language, and it is a markup language, not a programming language. HTML is purely text-based. It includes elements/tags that are enclosed in angle brackets. The browser receives the html file and renders the web page.

CSS

CSS is used to style the elements. It controls font families, sizes, weights, text alignments, and colors. It also determines where elements sit on a page. It handles visual flourishes without requiring heavy programming languages as well.

JavaScript

JavaScript is a programming language used to make web pages interactive and dynamic. It powers features like drop-down menus. It also fetchs new data from a server in the background and updates the text or graphics on the screen automatically. It can even listen and react to user inputs in real-time, such as mouse clicks, keyboard strokes, or scrolling.

Bootstrap

Bootstrap is a popular, open-source front-end framework used to design responsive, mobile-first websites quickly. It provides pre-built coding components like buttons, navigation bars, and forms using HTML, CSS, and JavaScript. By offering a flexible grid system, it ensures that your website automatically adapts and looks great on screens of all sizes.
